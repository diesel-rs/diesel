Struct JoiningGroup

pub struct JoiningGroup(/* private fields */);
Expand description

Enumerated property Joining_Group.

See Section 9.2, Arabic Joining Groups in The Unicode Standard for the summary of each property value.

use icu::properties::{CodePointMapData, props::JoiningGroup};

assert_eq!(
    CodePointMapData::<JoiningGroup>::new().get('ع'),
    JoiningGroup::Ain,
); // U+0639: Arabic Letter Ain
assert_eq!(
    CodePointMapData::<JoiningGroup>::new().get('ظ'),
    JoiningGroup::Tah,
); // U+0638: Arabic Letter Zah
