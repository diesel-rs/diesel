Expand description

A borrowed SQLite connection

This type is provided to various hook functions called by SQLite internally It mostly acts as &mut SqliteConnection with the additional constraint that you cannot move out/replace the inner connection handle

Any hook (update, commit, rollback, progress, wal, busy handler, authorizer, trace, collation needed) is reset after the closure that gets this connection type as argument ends. This specifically means that any hook registered during [register_auto_extension] won’t trigger later
