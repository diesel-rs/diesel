17/// A connection to a MySQL database. Connection URLs should be in the form
18/// `mysql://[user[:password]@]host/database_name`
19///
20/// # Cancellation and timeouts
21///
22/// Dropping a query future before it completes, for example when a timeout
23/// expires, can leave this connection with an unfinished operation. Such a
24/// connection must not be reused: drop it and establish a new connection
25/// instead. Cancelling the future does not guarantee that the server stopped
26/// executing the query or rolled back its effects.
27///
28/// The connection pool integrations detect this state and discard the broken
29/// connection when it is returned to the pool. Users managing connections
30/// without a pool must handle this themselves whenever they cancel or time out
31/// an operation.
32pub type AsyncMysqlConnection = AsyncMysqlLikeConnection<Mysql>;
