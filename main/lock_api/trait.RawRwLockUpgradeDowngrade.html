Expand description

Additional methods for RwLocks which support upgradable locks and lock downgrading.

§Safety

Implementations must uphold the safety requirements of RawRwLock for the additional methods provided by this trait. Downgrading from exclusive to upgradable access must release to subsequent lock acquisitions.
