Struct RawRwLock 

Source 
pub struct RawRwLock<const RECURSIVE: bool = false> { /* private fields */ }
Expand description

Raw reader-writer lock type backed by the parking lot.

If RECURSIVE is true, readers are prioritized over writers: acquiring a read lock is guaranteed not to block unless a writer currently holds the lock. This permits recursive read locking, but may starve writers.
