A doctest went past us, and then another that looked just like it.\n\n`cargo dejadoc` scans and canonicalizes every doctest your workspace\'s rustdoc would run, and on request every function, reporting any duplicates. Use it in your GitHub CI!\n\n![A pull request review by dejadoc, with an inline comment on a duplicated doctest and a suggestion that removes the copy](https://raw.githubusercontent.com/LucaCappelletti94/cargo-dejadoc/main/docs/review.png)\n\nThe flags under `cargo dejadoc --help` restrict the package, set the threshold and minimum token counts, turn the function check on, point at a config file, and switch the output to JSON.\nWithout flags, parameters come from `.dejadoc.toml` at the workspace root.\n\nGenerated files are skipped, a file being generated when one of its first five lines contains `@generated` or is a `// Code generated \u{2026} DO NOT EDIT.` line. In `.dejadoc.toml`, `generated-markers = [\"\u{2026}\"]` adds phrases of your own generators and `scan-generated = true` scans them anyway.\n\nThe first copy of a group is the one to keep. A copy whose code names its own item comes first, so a test copied from `parse` onto `lex` stays on `parse`. Otherwise file and line order decides.\n\nTo keep a copy on purpose, write `dejadoc` after `rust` on the opening line of its code block. rustdoc ignores the word and runs the doctest as before.\n\n````text\n/// ```rust,dejadoc\n/// let parsed = mycrate::parse(\"1\");\n/// ```\n````\n\nThe function check is off by default. `--functions`, `functions = true` in `.dejadoc.toml` or the action\'s `functions: true` turns it on.\n\nFunctions compare within their module, in every target and under every `cfg`. Two match when they differ only in their name, visibility, local names, formatting, or attributes such as `cfg`, `inline` and lint levels. A test marker, `should_panic` or `ignore` keeps them apart. A copy gets a suggestion to delete only when it is a free function or an inherent method under the same `cfg` as the copy kept, and is not already public API of a library, which is better made to call the kept copy or deprecated. Copies on different self types point to a generic or a macro, trait methods and exported symbols to a helper or a macro, and copies under different `cfg`s to one function under both. Functions whose body counts fewer than 30 tokens are skipped, the signature left out, a path like `core::str::from_utf8` or an operator like `=>` counting as one token and a comma as none. A `// dejadoc: allow` line above a function keeps it.\n\nIn CI, one workflow covers it. The [action](https://github.com/marketplace/actions/dejadoc) installs the crate, scans, and posts the findings as a pull request review, with every other input optional.\n\n```yaml\non: pull_request\njobs:\n  dejadoc:\n    runs-on: ubuntu-latest\n    permissions:\n      pull-requests: write\n    steps:\n      - uses: actions/checkout@v4\n      - uses: dtolnay/rust-toolchain@stable\n      - uses: LucaCappelletti94/cargo-dejadoc@v1\n        with:\n          # Review the pull request instead of failing the job. Drop it to gate a push.\n          pr-number: ${{ github.event.pull_request.number }}\n          # Report duplicates that predate the pull request too, default false.\n          only-new: false\n          # Report a group from this many copies, default 2.\n          threshold: 2\n          # Ignore doctests below this token count, default 0.\n          min-tokens: 0\n          # Check for duplicated functions too, default false.\n          functions: true\n          # Ignore functions whose body counts fewer tokens than this, default 30.\n          fn-min-tokens: 30\n          # Scan bin and example doctests as well as lib ones, default false.\n          all-targets: true\n          # Restrict to one workspace member, and scan from a subdirectory.\n          package: mycrate\n          cwd: .\n          # Annotate each copy to remove, default true.\n          annotations: true\n          # Render the review in the job summary instead of posting it.\n          dry-run: false\n          # Use the cargo dejadoc already on the path instead of installing one, default true.\n          install: true\n```\n\nReview mode reports only the duplicates your pull request introduces, comparing each site against a scan of the base commit. Comments land on the copies to remove, a kept copy never gets one. Each comment links the copy that survives and GitHub renders those lines right in the comment, long ones collapsed behind a show link. The link points at the base commit for pre-existing copies and at the first added copy for groups the pull request created, and the removal suggestion deletes the copy together with an empty line left behind. Sites GitHub cannot anchor get permalinks in the review body.\n\nEvery run also writes the report to the [job summary](https://docs.github.com/en/actions/reference/workflow-commands-for-github-actions#adding-a-job-summary) and one [annotation](https://docs.github.com/en/actions/reference/workflow-commands-for-github-actions#setting-an-error-message) per copy to remove, which GitHub anchors to the line in the diff. Annotations are workflow output rather than API calls, so they need no token and a fork pull request shows the findings whatever its token allows. The `--github` flag prints them from the command line too, beside the usual report.\n\nA fork\'s [`GITHUB_TOKEN`](https://docs.github.com/en/actions/security-for-github-actions/security-guides/automatic-token-authentication#permissions-for-the-github_token) is read-only, so the review cannot be posted there and the job passes on the annotations and the summary alone. 198    /// Doctests of `targets` grouped through `group_doctests`, then their functions.
199    fn scan(
200        self,
201        root: &str,
202        targets: &[TargetScan],
203        read: &IncludeRead<'_>,
204        group_doctests: fn(&[DocTest], usize, usize) -> Report,
205    ) -> Report {
206        let targets: Vec<&TargetScan> = targets
207            .iter()
208            .filter(|t| self.package.as_deref().is_none_or(|p| p == t.name))
209            .collect();
210        let threshold = self.threshold.unwrap_or(DEFAULT_THRESHOLD);
211        let scanned = |file: &SourceFile| {
212            self.scan_generated || !is_generated(&file.text, &self.generated_markers)
213        };
214        let mut report = group_doctests(
215            &extract_all(targets.iter().copied(), root, read, &scanned),
216            threshold,
217            self.min_tokens.unwrap_or(DEFAULT_MIN_TOKENS),
218        );
219        if self.functions {
220            // Targets sharing a root file are one crate, walked once.
221            let mut roots = BTreeSet::new();
222            let crates = targets
223                .iter()
224                .filter(|target| roots.insert(target.files.first().map(|f| f.path.as_str())));
225            let sites = crates.flat_map(|target| {
226                let crate_root = target.files.first().map_or("", |f| {
227                    f.path
228                        .strip_prefix(root)
229                        .map_or(f.path.as_str(), |p| p.trim_start_matches('/'))
230                });
231                target
232                    .files
233                    .iter()
234                    .filter(|file| scanned(file))
235                    .flat_map(move |file| {
236                        functions::functions(
237                            &module_prefix(target, file),
238                            file,
239                            root,
240                            crate_root,
241                            target.library,
242                        )
243                    })
244            });
245            let (total, unique, groups) = group_functions(
246                sites,
247                threshold,
248                self.fn_min_tokens.unwrap_or(DEFAULT_FN_MIN_TOKENS),
249            );
250            report.functions = total;
251            report.unique_functions = unique;
252            report.groups.extend(groups);
253        }
254        report
255    }
256}

310/// Whether `text` declares itself generated in its first five lines, where rustfmt looks: by
311/// `@generated`, by Go's `// Code generated … DO NOT EDIT.` line, or by one of `markers`.
312fn is_generated(text: &str, markers: &[String]) -> bool {
313    text.lines().take(5).any(|line| {
314        let line = line.trim();
315        line.contains("@generated")
316            || (line.starts_with("// Code generated ") && line.ends_with(" DO NOT EDIT."))
317            || markers.iter().any(|marker| line.contains(marker.as_str()))
318    })
319}

321/// The doctests of every file of `targets` rustdoc collects from and `scanned` keeps.
322fn extract_all<'t>(
323    targets: impl IntoIterator<Item = &'t TargetScan>,
324    root: &str,
325    read: &IncludeRead<'_>,
326    scanned: &dyn Fn(&SourceFile) -> bool,
327) -> Vec<DocTest> {
328    let mut blocks = Vec::new();
329    for target in targets {
330        for file in target.files.iter().filter(|f| f.rustdoc && scanned(f)) {
331            blocks.extend(extract::extract(
332                &module_prefix(target, file),
333                &file.path,
334                &file.parsed,
335                root,
336                read,
337            ));
338        }
339    }
340    blocks
341}

487/// `f` on a thread with `stack` reserved, or on the calling thread when the
488/// system refuses that thread.
489#[cfg(feature = "std")]
490fn on_large_stack<T: Send>(stack: usize, f: impl Fn() -> T + Sync) -> T {
491    std::thread::scope(|scope| {
492        match std::thread::Builder::new()
493            .stack_size(stack)
494            .spawn_scoped(scope, &f)

508/// `group` on the calling thread's stack.
509fn group_here(blocks: &[DocTest], threshold: usize, min_tokens: usize) -> Report {
510    let mut by_site: BTreeMap<(&str, u32), &DocTest> = BTreeMap::new();
511    for block in blocks {
512        by_site
513            .entry((block.file.as_str(), block.line))
514            .or_insert(block);
515    }
516    let total = by_site.len();
517    let entries = by_site.into_values().filter(|b| !b.allow).map(|block| {
518        let canonical = if block.info.iter().any(|tag| tag == "compile_fail") {
519            normalize::canonicalize_failing(&block.code)
520        } else {
521            normalize::canonicalize(&block.code)
522        };
523        let mut hashed = canonical.text.clone();
524        for tag in checked_attributes(&block.info) {
525            hashed.push('\n');
526            hashed.push_str(tag);
527        }
528        let hash = blake3::hash(hashed.as_bytes()).to_hex().to_string();
529        (
530            hash,
531            canonical.unparsed,
532            canonical.tokens,
533            (block.clone(), ()),
534        )
535    });
536    let (unique, groups) = bucket(Kind::Doctest, entries, threshold, min_tokens, |_| None);
537    Report {
538        total,
539        unique,
540        functions: 0,
541        unique_functions: 0,
542        groups,
543    }
544}

546/// The doctest attributes that change what rustdoc checks, sorted: `compile_fail` with its
547/// error codes, `should_panic`, `test_harness` and the edition. `no_run` only skips running.
548fn checked_attributes(info: &[String]) -> Vec<&str> {
549    let mut tags: Vec<&str> = info
550        .iter()
551        .map(String::as_str)
552        .filter(|tag| {
553            #[allow(non_exhaustive_omitted_patterns)] match *tag {
    "compile_fail" | "should_panic" | "test_harness" => true,
    _ => false,
}matches!(*tag, "compile_fail" | "should_panic" | "test_harness")
554                || tag.starts_with("edition")
555                || (tag.len() == 5
556                    && tag.starts_with('E')
557                    && tag[1..].bytes().all(|b| b.is_ascii_digit()))
558        })
559        .collect();
560    tags.sort_unstable();
561    tags
562}

564/// The function count, distinct forms and groups, each function canonicalized as a one-item file.
565fn group_functions(
566    sites: impl Iterator<Item = functions::FnSite>,
567    threshold: usize,
568    min_tokens: usize,
569) -> (usize, usize, Vec<Group>) {
570    let mut total = 0;
571    let entries = sites
572        .inspect(|_| total += 1)
573        .filter(|f| !f.site.allow)
574        .map(|f| {
575            let file = syn::File {
576                shebang: None,
577                frontmatter: None,
578                attrs: Vec::new(),
579                items: ::alloc::boxed::box_assume_init_into_vec_unsafe(::alloc::intrinsics::write_box_via_move(::alloc::boxed::Box::new_uninit(),
        [syn::Item::Fn(f.func)]))alloc::vec![syn::Item::Fn(f.func)],
580            };
581            let canonical = syn_canon::canonicalize(file);
582            let tokens = normalize::body_tokens(canonical.clone());
583            let keyed = ::alloc::__export::must_use({
        ::alloc::fmt::format(format_args!("{0}\n{1}", f.scope, canonical))
    })format!("{}\n{canonical}", f.scope);
584            let hash = blake3::hash(keyed.as_bytes()).to_hex().to_string();
585            (hash, false, tokens, (f.site, f.context))
586        });
587    let (unique, groups) = bucket(Kind::Function, entries, threshold, min_tokens, |sites| {
588        Some(functions::remedy(sites))
589    });
590    (total, unique, groups)
591}

593/// One hash's text fallback flag, token count and sites with their context.
594type Bucket<C> = (bool, usize, Vec<(DocTest, C)>);
595
596/// The distinct hash count of `entries` and their groups of at least `threshold` sites and
597/// `min_tokens` tokens, each site carrying the context `remedy` reads.
598fn bucket<C>(
599    kind: Kind,
600    entries: impl Iterator<Item = (String, bool, usize, (DocTest, C))>,
601    threshold: usize,
602    min_tokens: usize,
603    remedy: impl Fn(&[(DocTest, C)]) -> Option<Remedy>,
604) -> (usize, Vec<Group>) {
605    let mut unique: BTreeSet<String> = BTreeSet::new();
606    let mut by_hash: BTreeMap<String, Bucket<C>> = BTreeMap::new();
607    for (hash, unparsed, tokens, site) in entries {
608        unique.insert(hash.clone());
609        if tokens >= min_tokens {
610            by_hash
611                .entry(hash)
612                .or_insert_with(|| (unparsed, tokens, Vec::new()))
613                .2
614                .push(site);
615        }
616    }
617    let groups = by_hash
618        .into_iter()
619        .filter(|(_, (_, _, sites))| sites.len() >= threshold)
620        .map(|(hash, (unparsed, tokens, mut sites))| {
621            sites.sort_by(|(a, _), (b, _)| {
622                (a.file.as_str(), a.line).cmp(&(b.file.as_str(), b.line))
623            });
624            sites.sort_by_cached_key(|(site, _)| !names_its_item(site));
625            let remedy = remedy(&sites);
626            Group {
627                kind,
628                id: hash[..8].to_string(),
629                hash,
630                unparsed,
631                tokens,
632                sites: sites.into_iter().map(|(site, _)| site).collect(),
633                remedy,
634            }
635        })
636        .collect();
637    (unique.len(), groups)
638}

640/// Whether `site`'s code names its item, the last word of the item path
641/// appearing as a whole word. A copy that names another item was most
642/// likely copied from it, so the one naming its own item is kept.
643fn names_its_item(site: &DocTest) -> bool {
644    let word = |c: char| c.is_alphanumeric() || c == '_';
645    site.item
646        .rsplit(|c: char| !word(c))
647        .find(|name| !name.is_empty())
648        .is_some_and(|name| site.code.split(|c: char| !word(c)).any(|w| w == name))
649}
