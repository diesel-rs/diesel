9/// This struct tells our type system that the whatever we put in `values`
10/// will be handled by SQL as an expression of type `ST`.
11/// It also implements the usual `SelectableExpression` and `AppearsOnTable` traits
12/// (which is useful when using this as an expression). To enforce correctness here, it checks
13/// the dedicated [`ValidSubselect`]. This however does not check that the `SqlType` of
14/// [`SelectQuery`], matches `ST`, so appropriate constraints should be checked in places that
15/// construct Subselect. (It's not always equal, notably .single_value() makes `ST` nullable, and
16/// `exists` checks bounds on `SubSelect<T, Bool>` although there is actually no such subquery in
