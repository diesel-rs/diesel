Module sql_state 

Source
Available on crate feature postgres_backend only.
Expand description

The SQLSTATE codes PostgreSQL defines, as listed in its documentation and taken from errcodes.txt.

Each constant is named after PostgreSQL’s ERRCODE_ macro and documented with its PL/pgSQL condition name.

use diesel::pg::sql_state;
use diesel::result::SqlState;

fn retryable(code: SqlState) -> bool {
    matches!(
        code,
        sql_state::T_R_SERIALIZATION_FAILURE | sql_state::T_R_DEADLOCK_DETECTED
    )
}

assert!(retryable("40001".parse().unwrap()));
assert!(!retryable("23505".parse().unwrap()));
