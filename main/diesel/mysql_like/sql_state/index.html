Module sql_state 

Source
Available on crate features mariadb_backend or mysql_backend only.
Expand description

The SQLSTATE codes MySQL 8.4 and MariaDB 11.8 report, taken from messages_to_clients.txt and errmsg-utf8.txt.

use sqlstate::{SqlState, mysql_like};

let code: SqlState = "40001".parse().unwrap();
assert!(matches!(code, mysql_like::SERIALIZATION_FAILURE));
