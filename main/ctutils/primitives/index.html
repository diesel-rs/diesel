Module primitives 

Source
Expand description

Constant-time integer primitives for cryptographic arithmetic.

Core integer methods can lower to branches or table lookups on targets without the corresponding instructions. These helpers provide alternatives if value is zero-bit counting and carry propagation.

Like Choice, they use optimization barriers where needed. Their generated code should still be checked for the target and compiler in use.

Native zero counts are used when supported and advertised by the target configuration.
